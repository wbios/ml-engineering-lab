\# Esercise 02 - Transaction Analysis



\## Goal



The Goal of this exercise is to pratice data aggregation and analysis using Pandas.



The exercise focuses on calculating summary statistics and extracting insights from customer transaction data.



\## Dataset



The dataset contains transaction data with the following columns:



| Column | Description |

| ------ | ----------- |

|'customer\_id'| Unique customer identifier|

|'country'| Customer country|

|'category'| Product category |

|'amount'| Transaction amount|



\## Tasks



The 'analyze\_transactions()' function performs the following operations:



1. Calculate total sale.
2. Calculate the average transaction amount.
3. Identify the customer with the highest total spending.
4. Identify the category with the highest total revenue.
5. Calculate total sales by country.
6. Count the number of transactions per customer.



\## Technologies



* Python 3
* Pandas
